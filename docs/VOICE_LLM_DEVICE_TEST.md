# SpeakMate 小程序「语音 + 真实 LLM」真机联调注意事项

> 目标链路：**按住说话（ASR）→ 转英文文本 → 真实 LLM（LMStudio）生成回复 → TTS 朗读 + 逐句高亮 + 重播**
>
> 本文按「从底层到上层」的顺序列出每个环节的联调检查点、常见报错与排查顺序。真机联调前请逐条核对。

---

## 0. 联调前置总览（一句话版）

```
LMStudio(1234端口，已加载 qwen3.6-35b-a3b)
        ↓  http://localhost:1234/v1
后端 Node24(3001端口，.env 指向 lmstudio)
        ↓  http://192.168.x.x:3001（真机不能用 localhost）
小程序（真实 AppID + WechatSI 插件 + 隐私勾选麦克风；AppID 仅放本机配置）
```

三条独立链路必须**分别**打通，任何一条断都会表现为「语音没反应」：

| 链路 | 关键依赖 | 断了的表现 |
|------|---------|-----------|
| A. 真机 → 后端 | 局域网 IP + 关闭域名校验 | 点发送没反应 / 网络错误 |
| B. 后端 → LMStudio | 1234 端口 + 模型名一致 | 回复卡住 / 降级 / 报错 |
| C. 小程序 → 微信语音 | 插件授权 + 麦克风隐私声明 | 按住说报 scope / 没声音 |

---

## 1. 链路 A：真机连后端（最容易踩，先查这个）

### 1.1 后端地址不能用 localhost

手机（或真机预览）里的 `localhost` 指向**手机自己**，不是你的电脑。必须用局域网 IP。

- 查看电脑局域网 IP：`ipconfig`（找 IPv4，如 `192.168.x.x`）
- 小程序「我的」页 → 后端地址填 `http://192.168.x.x:3001`
- **手机和电脑必须在同一 Wi-Fi**

### 1.2 关闭域名校验（开发期必须）

真机预览时微信默认强制 HTTPS + 合法域名，`http://` 的局域网地址会被拦。

- 开发者工具：**详情 → 本地设置 → 勾选「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**
- 注意：这个勾选**只对开发者工具生效**；真机预览要额外在**预览二维码页面**打开「调试模式」（右上角 → 调试模式 / 开启开发者工具本地调试），否则真机仍可能拦 http。

### 1.3 后端要监听 0.0.0.0（而非 127.0.0.1）

后端默认监听 `0.0.0.0:3001`（前面 netstat 已确认 `TCP 0.0.0.0:3001 ... LISTENING`），手机才能访问。
若改成只绑 127.0.0.1，真机连不上——排查时先看 netstat 里是 `0.0.0.0` 还是 `127.0.0.1`。

### 1.4 Windows 防火墙

Windows 防火墙可能拦外部（手机）访问 3001 端口。若手机 ping 得通电脑但连不上后端，检查防火墙入站规则放行 3001，或临时关闭专用网络防火墙测试。

### 1.5 验证方法（分步定位）

```bash
# 电脑本机自测（排除后端自身问题）
curl http://localhost:3001/api/health

# 手机浏览器直接访问（排除小程序/域名校验问题）
# 手机浏览器打开 http://192.168.x.x:3001/api/health
# 能看到 {"code":0,...,"llm":{"provider":"lmstudio"...}} 即链路 A 通
```

## 2. 链路 B：后端 → LMStudio（真实 LLM）

### 2.1 三个前提

1. **LMStudio 已启动**并在 1234 端口监听：`netstat -ano | grep :1234`
2. **已加载正确模型**：LMStudio 里加载 `qwen3.6-35b-a3b`
3. **后端 `.env` 的模型名与 LMStudio 完全一致**（含前缀 `qwen/`）：
   ```ini
   LLM_PROVIDER=lmstudio
   LLM_BASE_URL=http://localhost:1234/v1
   LLM_MODEL=qwen/qwen3.6-35b-a3b
   LLM_API_KEY=lm-studio
   LLM_ENABLE_THINKING=false
   ```

### 2.2 验证后端确已切到真实 LLM

```bash
curl http://localhost:3001/api/health
# 关键看 llm 字段：
#   正确：{"llm":{"provider":"lmstudio","model":"qwen/qwen3.6-35b-a3b"}}
#   错误：{"llm":{"provider":"mock",...}}  → 说明 .env 没被加载
```

**常见坑**：如果 health 仍显示 `mock`，说明后端启动时没读到 `.env`。确认启动命令的工作目录在 `backend/` 下（dotenv 默认读 `./.env`）。

### 2.3 模型名不匹配的典型报错

LMStudio 里 `/v1/models` 返回的 `id` 才是真实模型名。若 `.env` 里 `LLM_MODEL` 写错（少了 `qwen/` 前缀、大小写、或版本号），请求会返回 404「model not found」。**以 LMStudio 界面上显示的模型名为准**。

### 2.4 LLM 首字慢是正常的

本地 qwen3.6-35b-a3b 生成首字可能需要几秒。小程序 `REQUEST_TIMEOUT = 30000`、流式首块等待 `8000ms` 已按此预留。若模型更大/机器更慢，首字超过 8 秒会触发「流式 → 非流式」降级——**功能仍可用，只是没有逐字打字效果**，不是 bug。

## 3. 链路 C：小程序 → 微信语音（ASR + TTS）

### 3.1 插件授权（编译期硬前提）

若 `requirePlugin('WechatSI')` 报「插件未授权」，是后台没加插件。已接入 `app.json`：
```json
"plugins": { "WechatSI": { "version": "0.3.5", "provider": "wx069ba97219f66d99" } }
```
后台：设置 → 第三方设置 → 插件管理，**直接粘贴插件 AppID `wx069ba97219f66d99`** 定位（关键词常搜不到）。

### 3.2 麦克风隐私声明（「按住说」报错的根因，主人必做）

「按住说」报 `start:fail api scope is not declared in the privacy agreement` 时，是**微信后台**的隐私指引没勾麦克风，不是代码问题。

- 小程序后台 → 设置 → 服务内容声明 → **用户隐私保护指引** → 勾选「麦克风（录音）」
- 代码侧已做的：`app.json` 的 `__usePrivacyCheck__: true` + `permission.scope.record` + 自定义隐私弹窗，都只是**代码层**；后台勾选是**独立**的、必须手动的一步。

### 3.3 麦克风运行时权限

首次「按住说话」会触发隐私协议 + `scope.record` 授权。若用户之前拒绝过，去「我的 → 隐私保护」或系统设置重新开启。代码里 `getSetting` 检测到未授权会弹「去设置」引导。

### 3.4 语音引擎要在「我的」页打开

默认 `speechEngine: 'text-only'`（纯文字）。要语音，必须到「我的」页把语音引擎切到 **wechat-si**。切换后回「练习」页，`onShow` 会重建适配器（已修复过「切了引擎按钮不出现」的问题）。

### 3.5 TTS 音色限制

微信同声传译插件的 `textToSpeech` **只有 lang/content，没有 voice 参数**，音色固定、偏机械。要更自然的音色只能接后端多音色 TTS（Azure / 讯飞 / 阿里云），属后续增强项，当前不做。

## 4. 语音 + LLM 全链路联调脚本（按顺序走一遍）

| 步骤 | 操作 | 预期 | 卡住时的排查 |
|------|------|------|-------------|
| 1 | 电脑 `curl :3001/api/health` | llm.provider=lmstudio | 见 §2.2 |
| 2 | 手机浏览器开 `http://IP:3001/api/health` | 看到 JSON | 见 §1.2/1.4 |
| 3 | 开发者工具点「练习」→ 选场景 | 出现真实 LLM 开场白 | 见 §2.3 |

| 8 | 点 AI 气泡「🔊 重播」 | 重新朗读整条 | 同上 |

## 5. 常见问题速查

| 现象 | 最可能原因 | 处理 |
|------|-----------|------|
| 点发送没反应 | 后端地址仍是 localhost / 未关域名校验 | §1.1 / §1.2 |
| health 显示 mock | `.env` 没被加载（cwd 不对）| §2.2 |
| 回复报 model not found | `.env` 模型名与 LMStudio 不一致 | §2.3 |
| 按住说报 scope is not declared | 后台隐私指引漏勾麦克风 | §3.2 |
| 按住说按钮不出现 | 语音引擎没切到 wechat-si | §3.4 |
| 有按钮但说话没转成文字 | 插件未授权 / 网络 | §3.1 + 开发者工具 console |
| 回复出来但不朗读 | 自动朗读开关没开 / 引擎不支持 TTS | 「我的」页检查 ttsEnabled |
| 朗读卡住没声音 | 单句合成失败被跳过 | 看 console 是否有 textToSpeech fail |
| 逐字流式变一次性出全 | 首字超 8s 降级（本地模型慢）| 正常，非 bug |
