## 二、上传代码

1. 微信开发者工具打开 `D:\Work\SpeakMate\miniprogram`
2. 点右上角 **「上传」**
3. 填写：
   - **版本号**：`1.0.0`
   - **项目备注**：`多用户版：微信静默登录 + 数据隔离；语音识别修复`（写清楚便于日后回溯）
4. 上传成功后，代码进入公众平台的「开发版本」

> ⚠️ 「不校验合法域名」这个勾选项**只影响本地调试**，跟上传无关，不用改。

## 三、设为体验版（推荐，不用等审核）

适用场景：**只给家人/朋友用，不想等 1–7 天审核。**

1. 微信公众平台 → **管理 → 版本管理**
2. 找到刚上传的开发版本 → 点 **「选为体验版」**
3. **成员管理 → 体验成员 → 添加**：填家人微信号（需管理员扫码确认）
4. 回到「版本管理」→ 体验版区域有个**二维码**，发给家人
5. 家人微信扫码即可打开使用

**体验版 vs 正式版：**

| | 体验版 | 正式版 |
|---|---|---|
| 谁能用 | 开发者 + 体验成员名单 | 所有微信用户（可搜索到） |
| 需要审核 | ❌ 不需要 | ✅ 需要（1–7 天） |
| 入口 | 扫体验版二维码 / 微信「最近使用」 | 微信搜索小程序名 |

> 体验成员有人数上限（按账号类型而定，一般几十人），家用足够。

## 四、正式版发布（要给很多人用时）

1. 版本管理 → 开发版本 → **「提交审核」**
2. 填写审核信息：
   - **功能页面**：选「练习」页
   - **测试账号**：不需要（微信静默登录，审核员扫码即可）
   - **补充说明**：说明是英语口语练习工具，语音仅用于识别用户自己说的话
3. 等待审核（1–7 天）
4. 审核通过 → **「发布」** → 全网可用

### 常见驳回原因（本项目相关）

| 驳回理由 | 规避方式 |
|---|---|
| 类目不符 | 选「教育 → 在线教育」或「工具 → 效率」 |
| 隐私协议与实际不符 | 已对齐（见 `docs/miniapp/隐私协议清单.md`） |
| 缺少功能截图 | 提交时上传 3–5 张页面截图 |
| 语音功能说明不清 | 补充说明里写清「仅用于用户主动按住说话时的语音转文字」 |

## 六、发版后如遇问题

**排查语音问题**（最常见）：

1. 在微信开发者工具 → Storage 面板 → 新增 `debug_voice` = `true`
2. 重新编译，真机按住说话
3. 查看后端日志：
   ```bash
   grep "\[diag\]" backend/data/speakmate-service.log | tail -30
   ```
4. 对照 `docs/miniapp/隐私协议清单.md` 第五节排查表

**判断服务是否已加载新代码**：找新旧行为差异的探针，比看进程 ID 可靠。
例如 `/api/tts` 无令牌访问：新版返回 401，旧版返回 200。
