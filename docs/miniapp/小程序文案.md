## 九、其他补充建议

1. **小程序端的代码**：当前仓库的 `frontend/` 是 H5（Vite + React）。微信小程序端需要单独写一套（语法相近但 API 不同），建议二期基于 `shared/` 共享契约用 Taro 3 或 uni-app 复用 80%+ 代码（架构预留已就位）。
2. **首版演示小程序**：可先把后端 mock 模式打包成小程序 Demo，先跑通审核流程；真实 LLM 能力待备案与正式域名配置完成后灰度。
3. **品牌一致性**：小程序名称、App 名称（SpeakMate 口语伴侣）、cnb 仓库（darrell/SpeakMate）三处保持一致**，便于用户跨平台识别。
