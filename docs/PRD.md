## 1. 产品概述

### 1.1 产品定位

**SpeakMate（口语搭子）** 是一款随身 AI 英语口语陪练移动端 H5 应用：按住说话即可与 AI 进行连续多轮英语语音对话。AI 像一位私人外教——听懂你、回应你、纠正你，并长期记住你的学习情况，让"随时随地开口练英语"成为日常。

### 1.2 目标用户

- **首发用户**：Darrell（王勤龙），资深软件工程师（DevOps 方向，正申请 AMD DevOps SDE 职位），中级英语水平，已有"每日学习 5 个实用英语词汇"习惯（释义/音标/例句/记忆技巧），核心痛点是**缺少真实开口场景**。
- **泛化人群**：需要职场英语的 IT 从业者；想利用碎片时间保持口语状态的中级学习者。

### 1.3 核心价值

1. **随时开口**：按住即说，通勤/午休/排队皆可练；戴耳机即可完成一次完整口语练习
2. **懂你的 AI**：记住你的常错表达、已掌握词汇、偏好场景，下次对话接着上次聊
3. **场景实战**：默认侧重 IT 职场（站会/Code Review/故障复盘/DevOps 运维/英文面试），生活场景补充
4. **即错即纠**：语法错误与不地道表达即时纠正，纠错以卡片形式随回复展示、不打断对话流
5. **生词即存**：对话中生词一键收录词汇本，自动补齐释义/音标/例句/来源上下文，衔接"每日 5 词"习惯

### 1.4 已确认技术约束（本 PRD 边界）

| 层面 | 选型 |
|------|------|
| 前端 | Vite + React + Tailwind CSS + MUI，移动端优先 H5 |
| 后端 | Node.js 轻量后端 + SQLite（对话历史/词汇本/学习画像） |
| LLM | 后端统一 OpenAI 兼容接口；云端（DeepSeek/通义千问/GPT）与本地 LMStudio（qwen3.6-35b-a3b）配置切换 |
| 语音 | Web Speech API（浏览器 ASR 识别 + TTS 播报）；识别不准时文字输入兜底 |
| 用户体系 | **多用户已落地**（P2-5）：小程序 wx.login 静默登录 / 邀请码登录，各人数据隔离；昵称服务端随机生成，不采集微信昵称头像 |
| 多端 | 首期仅 H5；前后端分离，预留微信小程序/Android/iOS 复用路径 |

## 5. UI / 交互设计说明

### 5.1 页面清单（首期 5 页）

| 页面 | 路由（建议） | 核心元素 |
|------|-------------|---------|
| 对话页（首页） | `/` | 顶栏：场景标签 + 切换入口 + 新会话；消息流：用户/AI 气泡、纠错卡片、TTS 播报状态；底栏：按住说话大按钮 + 键盘输入切换 |
| 场景选择页 | `/scenes` | 场景卡片网格：IT 职场区（5 个）+ 生活区（4 个）；"最近使用"标记；选定后开启新会话 |
| 词汇本页 | `/words` | 生词列表（时间倒序）：单词/音标/释义/来源场景；复习模式入口；左滑删除 |
| 历史会话页 | `/history` | 会话列表：日期 + 场景 + 轮数 + 首条摘要；点击进入只读回看 |
| 设置页 | `/settings` | TTS 开关与语速；当前 LLM provider 展示（只读）；学习画像摘要（P1-6）；数据与隐私说明 |

> 启动直达对话页：打开应用默认进入对话页（续上次会话或一键新建），保证"最短路径开口说话"。

### 5.2 语音对话完整交互闭环（核心流程）

1. **开场**：进入对话页，AI 发送场景开场白（文字 + TTS 播报）；老用户可选"接着上次聊"
2. **按住说话**：按住麦克风按钮 → 按钮进入录音态（波纹动画）→ 实时显示 ASR 中间识别文本（P1-2）
3. **松开识别**：ASR 定稿 → 识别文本上屏为待发送气泡，标注"点击可编辑"（识别不准的第一道兜底）
4. **发送**：文本连同会话历史 + 学习画像，经后端代理转发至 LLM（流式请求，Key 不出后端）
5. **AI 回复**：流式文字渲染 + 首句到达即启动 TTS 播报（不等整段生成完）；播报中显示状态与停止按钮（P1-1）
6. **纠错展示**：若本轮表达有问题，AI 回复下方渲染**纠错卡片**：❌ 原句 → ⚠️ 问题 → ✅ 正确说法 → 💡 一句话讲解；无错误不显示；默认折叠为一行摘要（如"2 处表达可优化"），点击展开，不遮挡对话流
7. **标记生词**：AI 消息气泡点「选词」→ 进入选词模式，点击单词/拖选短语 → 弹出词条卡（LLM 生成释义/音标/例句/来源上下文，生成中显示骨架屏）→「加入词汇本」
8. **循环**：回到第 2 步继续多轮对话；会话自动保存，中途刷新可无缝续聊
9. **跨会话延续**：下次新建会话时，AI 基于画像生成延续性开场（如 "Last time we talked about your incident review — how did the follow-up go?"）

**异常分支**：

| 异常 | 处理 |
|------|------|
| ASR 不可用（权限拒绝/浏览器不支持/微信内置浏览器） | 明确提示原因 + 自动切换键盘输入模式，对话不中断 |
| TTS 不可用 | 仅文字显示，顶栏提示 |
| LLM 请求失败/超时（15s） | 气泡显示失败态 + 重试按钮；本地 LMStudio 未连接时给出明确指引 |
| 弱网 | 发送中显示"发送中/已送达"状态 |

### 5.3 关键交互细节

- 按住说话：按压 ≥300ms 视为有效语音；快速误触则提示"长按说话"
- 纠错策略（默认，待确认 Q2）：显式语法错误必纠；地道性建议每轮 ≤2 条，避免打击表达意愿
- 词汇本入口常驻底部 Tab；标记成功 Toast 提示，可点击直达

## 6. 非功能需求

### 6.1 性能

- AI 回复首 token：云端 ≤3s、本地 LMStudio ≤8s；文字流式渲染，TTS 首句到达即播报
- 页面首屏 ≤3s（4G 网络）；词汇本/历史页打开 ≤1s
- 消息列表分页加载（每页 ≤50 条），长会话不卡顿

### 6.2 安全

- **LLM API Key 仅存后端**（环境变量/服务端配置），前端代码与网络请求零暴露；所有 LLM 请求由后端代理转发
- 后端对 LLM 报错做脱敏包装，不透传 provider 细节与 Key 信息
- 本地 LMStudio 仅局域网访问，不暴露公网；如需远程访问必须加鉴权
- 设置页隐私告知：浏览器 ASR 的音频由浏览器厂商服务处理

### 6.3 兼容性（移动端浏览器）

- **HTTPS 为部署硬性要求**：Web Speech API 的语音识别（SpeechRecognition）与麦克风权限仅在安全上下文（HTTPS / localhost）可用 → 生产部署必须配置 TLS（Let's Encrypt / Cloudflare 等）
- 浏览器优先级：Chrome/Edge Android（ASR 支持最佳）> iOS Safari（iOS 14.5+，可用但稳定性一般）> 微信内置浏览器（ASR 大概率不可用 → 自动降级文字输入模式）
- 视口适配：≥360px 宽；适配 iOS 安全区（刘海/底部横条）；深色模式跟随系统

### 6.4 可维护与多端扩展预留

- 前后端分离，REST API 设计（`/api/sessions`、`/api/chat`、`/api/words`、`/api/profile`），未来小程序/原生 App 直接复用
- 所有数据表含 user_id 字段（默认 `'default'`）
- LLM 接入层配置驱动（OpenAI 兼容协议），新增 provider 零/少量代码
- 语音能力封装为适配层（SpeechAdapter），未来可替换为原生 SDK，不侵入业务组件
